# Notes for marketing

Ideas that are not built. Each says what it is, why, and what it would take, so that it can be
picked up without this file's author in the room.

## The agent brings people back with work it did on its own

**The idea.** While a person is away from a project, their agent proposes something new for it: a
direction the story could take, a character, a scene, a cover, a first cut of a clip. It makes a
small version of it and sends it by email: "Look what your agent made while you were out." The
message shows the thing itself and has one button, back into the project at that point, where the
person keeps it, changes it, or drops it.

**Why.** A creative project stalls when the next step is unclear. A concrete proposal is easier to
react to than an empty conversation, and "my agent did this by itself" is a story people repeat.
It is the same rule the agent follows inside a conversation, keep the project moving, carried past
the end of the session.

**What it would take.**

- The person's consent, asked once and easy to withdraw: which projects, how often, and a spending
  limit for work nobody asked for. Unattended work spends the person's credits, so the limit is
  theirs and small by default.
- A scheduled run per project that decides whether there is something worth proposing (nothing is
  better than noise), makes it within the limit, and keeps it apart from the project's own work
  until the person accepts it.
- An email provider, a template that shows the picture, sound, or clip inline, and an unsubscribe
  link in every message.
- A way to measure it: opens, returns to the project, and how often the proposal is kept.

**What to decide first.** How often is welcome rather than tiresome, whether the first proposal is
free, and what the agent may never do unasked (publish, spend above the limit, change what the
person made).
